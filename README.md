# PSC_MSM_2025

Implementation and modification of the "Markov-switching multi-fractal model" (MSM) for cryptocurrency volatility modelling.

## Project Structure

The repository is structured in three main parts, following the progression of the report:

- `MSM_partie2/`  
  Contains the **basic implementation** of the MSM model. This part introduces fundamental concepts and a first version of the model.  
  Notebooks in this part are **pre-executed**.

- `MSM_partie3/`  
  Contains the **piecewise MSM implementation**. This section develops a more refined, segmented modeling approach.

- `MSM_partie4/`  
  Contains the **prediction module**. This part focuses on forecasting volatility using the previously built models.  
  Notebooks in this part are also **pre-executed**.

## Notes

- Each folder is self-contained with its own source code.
- Dependencies may vary slightly depending on the implementation.
